1 Introduction

Count data arise frequently in applied statistics: the number of physician office visits, the number of articles published, or the number of insurance claims. The simplest model for count data is the Poisson regression, which assumes that the mean equals the variance. In practice, two violations are common:

Overdispersion. The variance often exceeds the mean. The negative binomial (NB) model addresses this by introducing a dispersion parameter θ>0\theta > 0 so that Var(Yi)=μi+μi2/θ\text{Var}(Y_i) = \mu_i + \mu_i^2/\theta. As θ→∞\theta \to \infty the model reduces to the Poisson.

Excess zeros. Many count datasets contain more zeros than a Poisson (or even NB) distribution predicts. The zero-inflated negative binomial (ZINB) model (Lambert 1992) handles this through a two-component mixture: with probability πi\pi_i the observation is a structural zero (e.g., a person who never visits a doctor); with probability 1−πi1-\pi_i it comes from an NB distribution, which can itself produce zeros.

This report documents the nbzinbAmoah R package, which fits both models from scratch using iteratively reweighted least squares (IRLS) (McCullagh and Nelder 1989) and an expectation-maximisation (EM) algorithm — without any general-purpose optimizer. We benchmark our implementation against the reference functions MASS::glm.nb() (Venables and Ripley 2002) and pscl::zeroinfl() (Zeileis et al. 2008), and apply the package to the NMES1988 dataset from the AER package (Kleiber and Zeileis 2008).

2 Methods

2.1 Negative Binomial Regression

Let YiY_i be a count and xix_i a pp-vector of covariates, i=1,…,ni = 1, \ldots, n. The NB2 model assumes P(Yi=y)=Γ(y+θ)Γ(θ)y!(θθ+μi)θ(μiθ+μi)y,y=0,1,2,… P(Y_i = y) = \frac{\Gamma(y+\theta)}{\Gamma(\theta)\,y!} \left(\frac{\theta}{\theta+\mu_i}\right)^\theta \left(\frac{\mu_i}{\theta+\mu_i}\right)^y, \quad y = 0,1,2,\ldots with log link log⁡μi=ηi=xi⊤β+oi\log\mu_i = \eta_i = x_i^\top\beta + o_i, where oio_i is an optional offset. Then E(Yi)=μiE(Y_i) = \mu_i and Var(Yi)=μi+μi2/θ\text{Var}(Y_i) = \mu_i + \mu_i^2/\theta. With prior weights aia_i (ai=1a_i = 1 for an ordinary fit) the log-likelihood is ℓ(β,θ)=∑i=1nai[log⁡Γ(yi+θ)−log⁡Γ(θ)−log⁡yi!+θlog⁡θ+yilog⁡μi−(θ+yi)log⁡(θ+μi)]. \ell(\beta,\theta) = \sum_{i=1}^n a_i\Bigl[\log\Gamma(y_i+\theta) - \log\Gamma(\theta) - \log y_i! + \theta\log\theta + y_i\log\mu_i - (\theta+y_i)\log(\theta+\mu_i)\Bigr]. This is the parameterisation used by MASS::glm.nb(), whose theta is the same θ\theta.

IRLS for β\beta (with θ\theta fixed). For a GLM with log link and variance V(μ)=μ+μ2/θV(\mu) = \mu + \mu^2/\theta, Fisher scoring is equivalent to repeated weighted least squares with working weights and working response wi=ai(∂μi/∂ηi)2V(μi)=aiθμiθ+μi,zi=(ηi−oi)+yi−μiμi, w_i = a_i\,\frac{(\partial\mu_i/\partial\eta_i)^2}{V(\mu_i)} = a_i\,\frac{\theta\,\mu_i}{\theta + \mu_i}, \qquad z_i = (\eta_i - o_i) + \frac{y_i - \mu_i}{\mu_i}, β(t+1)=(X⊤WX)−1X⊤Wz,W=diag(w1,…,wn). \beta^{(t+1)} = (X^\top W X)^{-1} X^\top W z, \qquad W = \text{diag}(w_1,\ldots,w_n). The weighted least-squares step is computed with solve(); lm(), lm.wfit() and glm.fit() are not used.

Newton–Raphson for θ\theta (with β\beta fixed). The score and second derivative of ℓ\ell with respect to θ\theta are U(θ)=∑iai[ψ(yi+θ)−ψ(θ)+log⁡θ+1−log⁡(θ+μi)−yi+θθ+μi], U(\theta) = \sum_i a_i\Bigl[\psi(y_i+\theta) - \psi(\theta) + \log\theta + 1 - \log(\theta+\mu_i) - \frac{y_i+\theta}{\theta+\mu_i}\Bigr], H(θ)=∑iai[ψ′(yi+θ)−ψ′(θ)+1θ−2θ+μi+yi+θ(θ+μi)2], H(\theta) = \sum_i a_i\Bigl[\psi'(y_i+\theta) - \psi'(\theta) + \frac{1}{\theta} - \frac{2}{\theta+\mu_i} + \frac{y_i+\theta}{(\theta+\mu_i)^2}\Bigr], where ψ\psi and ψ′\psi' are digamma() and trigamma(). We update ϕ=log⁡θ\phi = \log\theta, which keeps θ>0\theta > 0. By the chain rule Uϕ=θUU_\phi = \theta U and Hϕ=θ2H+θUH_\phi = \theta^2 H + \theta U, and the update is ϕ←ϕ−Uϕ/Hϕ\phi \leftarrow \phi - U_\phi / H_\phi.

Standard errors. At convergence, Var̂(β̂)=(X⊤ŴX)−1\widehat{\text{Var}}(\hat\beta) = (X^\top\hat W X)^{-1}, treating θ̂\hat\theta as known as glm.nb() does, and SE(θ̂)={−H(θ̂)}−1/2\text{SE}(\hat\theta) = \{-H(\hat\theta)\}^{-1/2}. The package stores SE(log⁡θ̂)=(−Hϕ)−1/2\text{SE}(\log\hat\theta) = (-H_\phi)^{-1/2}. Because U(θ̂)=0U(\hat\theta) = 0 at the MLE, Hϕ=θ̂2HH_\phi = \hat\theta^2 H, so SE(θ̂)=θ̂SE(log⁡θ̂)\text{SE}(\hat\theta) = \hat\theta\,\text{SE}(\log\hat\theta).

2.2 Zero-Inflated Negative Binomial Regression

The ZINB model is a two-component mixture. Let Di=1D_i = 1 if observation ii is a structural zero, with P(Di=1)=πiP(D_i = 1) = \pi_i; otherwise YiY_i comes from an NB(μi,θ)\text{NB}(\mu_i, \theta) distribution, which can itself produce zeros: P(Yi=0)=πi+(1−πi)fNB(0;μi,θ),P(Yi=y)=(1−πi)fNB(y;μi,θ),y≥1, P(Y_i = 0) = \pi_i + (1-\pi_i)\,f_\text{NB}(0;\mu_i,\theta), \qquad P(Y_i = y) = (1-\pi_i)\,f_\text{NB}(y;\mu_i,\theta), \quad y \ge 1, where fNB(0;μ,θ)={θ/(θ+μ)}θf_\text{NB}(0;\mu,\theta) = \{\theta/(\theta+\mu)\}^\theta, log⁡μi=xi⊤β+oi\log\mu_i = x_i^\top\beta + o_i (count model) and logitπi=zi⊤γ\text{logit}\,\pi_i = z_i^\top\gamma (zero-inflation model). The covariates ziz_i may differ from xix_i, and the marginal mean is E(Yi)=(1−πi)μiE(Y_i) = (1-\pi_i)\mu_i. The observed-data log-likelihood is ℓ(β,γ,θ)=∑i:yi=0log⁡[πi+(1−πi)fNB(0;μi,θ)]+∑i:yi>0[log⁡(1−πi)+log⁡fNB(yi;μi,θ)]. \ell(\beta,\gamma,\theta) = \sum_{i:\,y_i=0}\log\bigl[\pi_i + (1-\pi_i)\,f_\text{NB}(0;\mu_i,\theta)\bigr] + \sum_{i:\,y_i>0}\bigl[\log(1-\pi_i) + \log f_\text{NB}(y_i;\mu_i,\theta)\bigr]. Because of the mixture, ℓ\ell is not the log-likelihood of an exponential-family GLM, so IRLS cannot be applied to it directly (pscl::zeroinfl() maximises it with the general-purpose optimiser BFGS). Instead we use an EM algorithm (Dempster et al. 1977) that treats DiD_i as missing data. Given DiD_i, the complete-data log-likelihood splits into a logistic part in γ\gamma and a weighted NB part in (β,θ)(\beta, \theta), and each part can be fitted by IRLS.

E-step. Given the current (β,γ,θ)(\beta, \gamma, \theta), compute the posterior probability that observation ii is a structural zero: τi=P(Di=1∣yi)={πiπi+(1−πi)fNB(0;μi,θ)yi=0,0yi>0. \tau_i = P(D_i = 1 \mid y_i) = \begin{cases} \dfrac{\pi_i}{\pi_i + (1-\pi_i)\,f_\text{NB}(0;\mu_i,\theta)} & y_i = 0,\\ 0 & y_i > 0. \end{cases}

M-step (zero part). Maximise ∑i[τilog⁡πi+(1−τi)log⁡(1−πi)]\sum_i[\tau_i\log\pi_i + (1-\tau_i)\log(1-\pi_i)] over γ\gamma. This is a logistic regression with a fractional response τi\tau_i, fitted by IRLS with wi=πi(1−πi),z̃i=zi⊤γ+τi−πiπi(1−πi),γ←(Z⊤WZ)−1Z⊤Wz̃. w_i = \pi_i(1-\pi_i), \qquad \tilde z_i = z_i^\top\gamma + \frac{\tau_i - \pi_i}{\pi_i(1-\pi_i)}, \qquad \gamma \leftarrow (Z^\top W Z)^{-1} Z^\top W \tilde z. (We write z̃i\tilde z_i for the working response, to distinguish it from the covariate vector ziz_i.)

M-step (count part). Maximise ∑i(1−τi)log⁡fNB(yi;μi,θ)\sum_i(1-\tau_i)\log f_\text{NB}(y_i;\mu_i,\theta) over (β,θ)(\beta,\theta). This is exactly the NB fit of Section 2.1 with prior weights ai=1−τia_i = 1-\tau_i, so the same IRLS and Newton–Raphson updates are reused.

Convergence. The E- and M-steps are repeated until the observed-data log-likelihood ℓ(β,γ,θ)\ell(\beta,\gamma,\theta) changes by less than the tolerance. EM never decreases ℓ\ell; zinbreg() checks this at every iteration and issues a warning if it ever happens.

Standard errors. EM does not produce standard errors. We compute the observed information matrix as the negative Hessian of our own observed-data log-likelihood with respect to (β,γ,log⁡θ)(\beta, \gamma, \log\theta) at the MLE, using numDeriv::hessian() (numerical differentiation, not optimisation), and invert it. As zeroinfl() does, we report log⁡θ̂\log\hat\theta with its standard error, and also θ̂\hat\theta.

2.3 Algorithms and Convergence Criteria

NB (nbreg()). β\beta starts from one Poisson-type weighted least-squares step: log⁡max⁡(yi,0.5)−oi\log\max(y_i, 0.5) - o_i is regressed on XX with weights max⁡(yi,0.5)\max(y_i, 0.5), which is a Poisson IRLS step started from μi=yi\mu_i = y_i. θ\theta starts from the moment estimator θ̂0=y‾2/(s2−y‾)\hat\theta_0 = \bar y^2 / (s^2 - \bar y) (set to 1 if s2≤y‾s^2 \le \bar y, and at least 0.1). The outer loop alternates (a) IRLS for β\beta, iterated until max⁡j|Δβj|<10−10\max_j|\Delta\beta_j| < 10^{-10}, and (b) Newton–Raphson for log⁡θ\log\theta. It stops when the log-likelihood changes by less than epsilon (default 10−810^{-8}), or after maxit (default 200) outer iterations.

ZINB (zinbreg()). (β,θ)(\beta, \theta) start from an nbreg() fit of the count model. γ\gamma starts with its intercept at the logit of the observed proportion of zeros and its other coefficients at zero. Each EM iteration runs one E-step and both M-steps, and the algorithm stops when ℓ\ell changes by less than epsilon (default 10−810^{-8}), or after maxit (default 300) iterations. The benchmarks below use the tighter epsilon = 1e-10.

3 The R Package

3.1 Design and Main Functions

The nbzinbAmoah package exports four user-facing functions:

Function Purpose
nbreg(formula, data, offset, control, weights) NB regression via IRLS + Newton–Raphson for θ\theta
zinbreg(formula, data, offset, control, weights) ZINB via EM with IRLS M-steps
nbreg_control(maxit, theta_maxit, epsilon, trace) Tolerances and iteration limits for nbreg
zinbreg_control(maxit, irls_maxit, theta_maxit, epsilon, trace) Tolerances and iteration limits for zinbreg

Both fitting functions return S3 objects (classes "nbreg" and "zinbreg") containing the coefficients, variance–covariance matrix, θ̂\hat\theta and its standard error, log-likelihood, number of iterations, a convergence flag, fitted values and the matched call. Methods are provided for print, summary (a coefficient table of estimates, SEs, zz values and pp-values, printed by a print.summary method), coef, vcov, logLik (with a df attribute, so AIC() and BIC() work), fitted, residuals (type = "response" or "pearson"), nobs, and predict (with newdata). For zinbreg, coef() and vcov() take model = "count", "zero" or "full", and predict() supports type = "response" ((1−π)μ(1-\pi)\mu), "count" (μ\mu) and "zero" (π\pi).

The zinbreg formula uses the two-part syntax y ~ x1 + x2 | z1 + z2 from the Formula package: count-model covariates before the bar and zero-model covariates after it. Without |, the same covariates are used in both parts, as in zeroinfl().

For ZINB the dispersion row is log⁡θ\log\theta, as reported by zeroinfl.

Dispersion. The NB model estimates θ̂\hat\theta = 1.207 (SE of log⁡θ̂\log\hat\theta = 0.028). At the mean visit count of 5.77, the NB variance μ+μ2/θ\mu + \mu^2/\theta is therefore about 33.4, compared with 5.77 under the Poisson model. The ZINB count part has log⁡θ̂\log\hat\theta = 0.394 (SE 0.035), θ̂\hat\theta = 1.483.

For the NB model each additional hospital stay is associated with 24% more physician visits. People in poor health make 36% more visits than people in average health. Those in excellent health make 29% fewer visits. Each chronic condition is associated with 19% more visits. Men make 12% fewer visits than women. Having insurance is associated with 25% more visits.

The ZINB count part shows the same pattern as the NB model; hospital stays, poor health, chronic conditions, and insurance all increase visits, while excellent health and being male reduce visits. The effects are slightly smaller because some zeros are now handled by the zero part.

The zero part shows who never visits a doctor. People with chronic conditions are less likely to be non-visitors (OR = 0.287) because they have no choice but to seek care. Men are almost twice as likely as women to never visit a doctor (OR = 1.911). People with insurance are much less likely to be non-visitors (OR = 0.309), suggesting cost keeps some people away. More education also slightly reduces the chance of never visiting (OR = 0.920). Hospital stays were not significant with p = 0.057.

6.5 Model Choice

The Poisson model fits very poorly. Its log-likelihood is 5801 lower than the NB model’s, and it predicts only 47 zeros against 683 observed. Allowing overdispersion fixes most of the problem, but the NB model still under-predicts zeros (608 expected). The ZINB model improves the log-likelihood by a further 79.8 with 6 extra parameters, predicts 709 zeros, and has the lowest AIC and the lowest BIC.

We therefore prefer the ZINB model for NMES1988. For the bioChemists data in Appendix A of the project description, BIC favoured the simpler NB model; here, the evidence for excess zeros is strong enough to survive BIC’s larger penalty. The zero part also adds a useful interpretation: it identifies a group of structural non-users of physician care, who are more likely to be male, uninsured, less educated and to have fewer chronic conditions.

7 Discussion

This project implemented NB and ZINB regression from scratch, using only IRLS and Newton–Raphson (NB) and an EM algorithm with IRLS M-steps (ZINB). No general-purpose optimizer was used in the fitting code.

The benchmarking results confirm that our implementation reproduces MASS::glm.nb() to within 3.72e-10 and pscl::zeroinfl() to within 1.51e-05 for coefficients, with log-likelihood differences of at most 9.97e-10. These are well within the required tolerances (10−510^{-5} for NB and 10−310^{-3} for ZINB coefficients).

The simulation study (RR = 100, nn = 500) shows that zinbreg() reliably recovers known ZINB parameters with negligible bias and well-calibrated 95% Wald intervals (empirical coverage 0.93–0.95).

Limitations. First, the NB standard errors for β\beta treat θ\theta as known, as glm.nb() does, so they ignore the uncertainty in θ̂\hat\theta. Second, the ZINB standard errors use a numerical Hessian, which is slower and can be less accurate than an analytic one. Third, EM converges linearly, so zinbreg() needs many iterations and is several times slower than zeroinfl() (see the timing table). Fourth, offsets are supported in the count model only, not in the zero model. Finally, in the NMES1988 analysis the zero-model covariates follow the project description, and the choice between NB and ZINB relies on information criteria rather than a formal test, because the usual likelihood-ratio test is non-standard when the null value πi=0\pi_i = 0 lies on the boundary of the parameter space.

Possible extensions include an analytic Hessian for the ZINB standard errors, an offset in the zero model, acceleration of the EM algorithm (for example, switching to Newton–Raphson near convergence), and a formal score test for zero inflation.
